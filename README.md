# NeoVerse

> Experimental React and Three.js scene editor and mock collection UI. See [PUBLICATION.md](PUBLICATION.md) for verification and limits.

## Описание

Крупный frontend-прототип на React, Vite и Three.js для приложения, в котором пользователь получает цифровые 3D-объекты, собирает из них собственные пространства, публикует сцены и взаимодействует с маркетом и социальной частью.

По структуре это уже не просто экранный макет, а задел под полноценный продукт: есть роутинг, onboarding, страницы коллекции и профиля, редактор пространства, маркет, UI-компоненты и 3D-сцены.

## Основные разделы

- главная страница и onboarding;
- список и просмотр пространств;
- редактор 3D-пространства;
- market/collection flow;
- профиль пользователя;
- инфраструктура для UI-компонентов, уведомлений и состояния приложения.

## Стек

- React
- TypeScript
- Vite
- Three.js
- React Three Fiber / Drei
- React Router
- TanStack Query
- Tailwind + shadcn/ui

## Запуск

1. Установите зависимости: `npm install`
2. Поднимите dev-сервер: `npm run dev`
3. Для сборки используйте: `npm run build`
4. Для тестов доступна команда: `npm test`

## Статус

WIP. Проект выглядит как продуктовый концепт с заметной глубиной проработки, но это всё ещё активная разработка: часть сценариев и экранов работает как прототип, а не как завершённый production-frontend.
