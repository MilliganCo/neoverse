# Концепт приложения: ежедневные 3D-объекты и личные пространства для композиций (Detailed)

> Рабочее название: **NeoVerse** 

## 1) Короткое резюме
Приложение выдаёт пользователю **ежедневный дроп 3D‑объектов** (разная форма, материал/цвет, спецэффекты, редкость, статичность/динамика). Пользователь размещает объекты в **личных 3D‑пространствах** и строит композиции (арт‑инсталляции, мини‑скульптуры, «диорамы»). Пространства могут быть **приватными и публичными**. Публичные пространства участвуют в **оценивании и лидербордах**. Есть **рынок объектов и пространств**: покупка/продажа, аукционы и выкуп.

---

## 2) Для кого (целевые сегменты)
- **Креаторы и дизайнеры**: быстрый «скетчинг в 3D», коллекционирование редкостей, публичные галереи.
- **Игровая аудитория**: ежедневный лут, сбор сетов, соревнование в лидербордах.
- **Casual‑пользователи**: расслабляющее конструирование «красивых комнат»/сцен.

---

## 3) Основная ценность
- **Ежедневная причина возвращаться**: дроп + прогресс коллекции.
- **Творчество без порога входа**: простые инструменты сборки (snap, rotate, scale, материалы/свет).
- **Социальное признание**: рейтинги, подборки, «галереи» и продажи.
- **Экономика**: рынок стимулирует долгосрочное вовлечение (редкости, спрос на «площадки» и уникальные объекты).

---

## 4) Core loop (ядро)
1. Пользователь заходит → получает **ежедневный дроп** (Free: 1 объект/день; Pro: 2 объекта/день; Pro+: 3 объекта/день).
2. Открывает одно из пространств → размещает/комбинирует объекты.
3. Запускает **7‑секундную симуляцию** (если есть динамические объекты): «сцена оживает».
4. Сохраняет композицию → публикует (если публичное пространство) → получает оценки/рост в лидербордах.
5. При желании выставляет объект/пространство на рынок → покупает/продаёт.

---

## 5) Объекты: свойства и генерация

### 5.1 Атрибуты объекта
- **Геометрия**: примитивы (cube/sphere/torus), составные формы, «органика», procedural‑варианты.
- **Материал/цвет**: палитры, градиенты, PBR‑сеты (матовый пластик, стекло, металл и т.д.).
- **Спецэффект** (опционально):  
  - горение/эмиссия/неон  
  - хром/зеркало  
  - голография/иризация  
  - «музыкальный» (реакция на звук/ритм)  
  - световые следы/частицы  
- **Статичность/динамика**:
  - статичный: фиксирован в сцене
  - динамический: имеет **импульс/силу**, направление, поведение (spin, bounce, drift, orbit)
- **Редкость**: Common / Uncommon / Rare / Epic / Legendary / Mythic (пример).
- **Серии и сеты**: тематические «коллекции» (например, Chromatic, Ember, Mirror, AudioPulse).

### 5.2 7‑секундное пространство взаимодействия
- Любая сцена может иметь режим **“Play 7s”**:
  - запуск динамических объектов с параметрами силы/направления
  - ограничение времени помогает делать «короткие перформансы»
  - можно сохранить «лучший дубль» как реплей/мини‑ролик (опция для будущего)

### 5.3 Баланс редкости (направление, без чисел)
- Free: базовая вероятность редких выше порога минимальна.
- Pro: повышенный шанс на редкости + дополнительный объект/день.
- Ограничения/механики защиты экономики:
  - лимиты на «перепродажу» для новых аккаунтов
  - anti‑bot и rate limiting
  - отслеживание аномалий рынка

---

## 6) Пространства (Spaces)

### 6.1 Типы и приватность
- У пользователя есть набор пространств:
  - **Private**: видит только владелец (и, при необходимости, приглашённые)
  - **Public**: видят все, можно голосовать и комментировать (если включено)
- План Free:
  - **1 публичное + 1 приватное**
- План Pro:
  - больше пространств (например, 3–10, настраивается)
  - повышенный шанс редких
  - +1 объект в ежедневном дропе
- План Pro+:
  - всё из Pro
  - +1 объект в ежедневном дропе
  - **Magic Finger** (см. ниже)

### 6.2 «Конструирование» пространства
Пространство — это 3D‑сцена с параметрами:
- фон/окружение (нейтральная студия, night city, void, pastel room…)
- освещение (пресеты + ручная настройка)
- «гравитация»/физика (вкл/выкл, сила)
- сетка, snap‑направляющие, ограничения размеров
- камера (сохранённые ракурсы)

### 6.3 Публикация
- Публикация фиксирует:
  - список объектов, их трансформы, материалы, параметры симуляции
  - превью‑скриншот/обложку
  - короткий реплей (опционально, если 7‑секундный режим)

---

## 7) Magic Finger (Pro+)
Режим «игры» с чужими публичными пространствами:
- пользователь может «трогать»/двигать элементы, запускать 7‑секундный режим
- **без сохранения изменений** (эпhemeral сессия)
- видимые эффекты:
  - «призрачная рука», лёгкая вибро/звук
  - ограничения анти‑грифа:
    - тайм‑лимит на взаимодействие
    - отключаемость владельцем
    - автоматическое «сбросить сцену» после сессии

---

## 8) Социальные механики и лидерборды

### 8.1 Оценка/голосование
- быстрые реакции (например: ⭐ / 🔥 / 💎) или шкала 1–5
- ограничение: N голосов в день, чтобы снижать накрутку
- пользователь видит:
  - общий рейтинг
  - рост/падение места в лидерборде
  - подборки «топ недели», «новички», «по тематике»

### 8.2 Несколько лидербордов
- **Daily/Weekly/All‑time**
- по темам/сезонам (например, Mirror Week)
- по ограничениям (например, «только Common» — челлендж‑таблица)

### 8.3 Профиль
- галерея публичных пространств
- витрина продаваемых объектов/пространств
- значки/ачивки (коллекции, топ‑попадания)

---

## 9) Рынок (Market)

### 9.1 Торговые сущности
- **Объекты** (инстансы) — продаются как предметы с метаданными и историей.
- **Пространства** — продаются как «сцена» (композиция + оформление).  
  Возможны варианты:
  - продажа «как есть»
  - продажа «шаблона» (копия без уникальных объектов — если разрешено экономикой)

### 9.2 Механики
- **Фиксированная цена** (buy now)
- **Аукцион** (bidding):
  - стартовая цена
  - шаг ставки
  - время окончания
  - опционально «мгновенный выкуп» (buyout)
- Комиссия платформы + возможные лимиты для защиты от фрода.

### 9.3 Внутренняя валюта
Два направления (выбрать одно):
1) только фиат через сторы (IAP) + баланс токенов внутри  
2) гибрид: earn‑through‑activity + IAP‑пополнение  
Важно: исключить трактовку как азартные механики — «ставка» = **bid в аукционе**.

---

## 10) Модерация и безопасность
- Контент‑политика для публичных пространств:
  - запрет на NSFW/хейт/экстремизм/пиратские логотипы (по правилам)
- Репорты: «пожаловаться на пространство/профиль»
- Автомодерация:
  - ограничение загрузки пользовательских текстур на старте (если появится)
  - анализ метаданных, анти‑спам
- Рынок:
  - лимиты на операции для новых аккаунтов
  - мониторинг подозрительных цепочек перепродаж

## 11) Продуктовые экраны (уровень системы)
- Onboarding + выбор первого пространства (public/private)
- Daily Drop (раскрытие «капсулы»)
- Inventory (объекты, фильтры по редкости/сетам)
- Space Editor (строительство)
- Play 7s (запуск симуляции + запись)
- Publish (обложка, теги)
- Explore (лента пространств, подборки)
- Leaderboards (таблицы)
- Market (листинги, поиск)
- Profile (галерея, продажи, коллекции)
- Subscription/Paywall (Free/Pro/Pro+)

---

## 12) Техническое направление (MVP‑уровень)
- Клиент: мобильный (iOS/Android) или WebGL — зависит от выбора платформы.
- 3D: Unity / Unreal / Three.js (для Web).
- Сервер: аккаунты, инвентарь, сцены, лидерборды, рынок, платежи.
- Хранение:
  - сцена = JSON (объекты + трансформы + параметры)
  - превью = изображения
  - реплеи = короткие видео/кадры (опционально)

---

## 13) Метрики успеха (MVP)
- D1/D7/D30 retention
- доля пользователей, открывающих daily drop
- доля пользователей, сохраняющих/публикующих пространство
- среднее время в редакторе
- голосования на пользователя/день
- конверсия в Pro/Pro+
- оборот рынка, ликвидность (кол-во сделок/листингов)

---

## 14) MVP → v1 Roadmap (кратко)
**MVP**
- daily drop
- 2 пространства (1 public, 1 private) для Free
- редактор (place/rotate/scale, snap, 2–3 пресета света)
- публикация + простой рейтинг
- лидерборд (weekly)
- базовый рынок: фиксированная цена (объекты)

**v1**
- аукционы + buyout
- реплеи 7‑секундных сцен
- расширенные материалы/эффекты
- тематические сезоны/ивенты
- Pro+ Magic Finger
