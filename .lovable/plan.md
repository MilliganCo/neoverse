# 3D Spaces — UI-прототип

## Визуальный стиль

Тёмная и светлая тема с gradient & glassmorphism: полупрозрачные карточки с backdrop-blur, градиентные акценты (фиолетовый → голубой → розовый (И более светлые в светлой теме)), неоновые (или мятные в светлой теме) бейджи редкости, плавные микро-анимации. Мобильно-ориентированный layout (bottom tab bar).

## Навигация

Нижний таб-бар с 5 вкладками: **Drop** / **Inventory** / **Spaces** / **Explore** / **Profile**. Market доступен из Explore и Profile.

---

## Этап 1: Онбординг + Daily Drop

### Онбординг (3 шага)

1. Welcome-экран с анимированным 3D-объектом (вращающийся куб) и текстом «Каждый день — новый 3D-объект»
2. Выбор никнейма + аватар (пресеты)
3. Автосоздание 2 пространств (Private + Public) → переход к первому дропу

### Daily Drop

- Полноэкранная 3D-сцена с анимацией «раскрытие капсулы» (частицы, вспышка)
- Карточка объекта: название, сет, редкость (цветной бейдж с glow-эффектом), тип (static/dynamic)
- Кнопки: **Add to Space**, **Inspect** (3D-вращение), **Share**
- Подсказка «Завтра новый дроп» внизу

---

## Этап 2: Inventory + Spaces

### Inventory

- Сетка карточек объектов с 3D-превью (вращающиеся миниатюры)
- Фильтры: редкость, эффект, сет, тип
- Тап на карточку → детальный просмотр с Inspect (полноэкранный 3D)

### Spaces (список)

- Карточки-превью пространств в сетке
- Фильтр Public / Private
- На карточке: название, статус, лайки/рейтинг, метка «On sale»
- Кнопка «+» для нового пространства (ведёт на paywall для Free)

---

## Этап 3: Space Editor (3D-редактор)

- **3D-сцена** (React Three Fiber) — основная область, ~75% экрана
- **Нижняя панель** — горизонтальный скролл объектов из инвентаря (drag-and-drop в сцену)
- **Боковая панель** (по кнопке) — настройки: освещение (пресеты), фон, snap grid, физика
- **Инструменты**: перемещение, вращение, масштаб объектов (gizmo-контролы)
- **Undo/Redo**, Duplicate, Delete
- **Кнопка Play 7s** — запуск анимации динамических объектов с таймером
- **Publish** — выбор обложки, теги, переключение public/private

---

## Этап 4: Explore + Leaderboards

### Explore

- Лента карточек-превью публичных пространств (masonry/сетка)
- Быстрые реакции (⭐🔥💎), счётчик
- Тап → полноэкранный 3D-просмотр пространства
- Кнопка Magic Touch (Pro+ бейдж)

### Leaderboards

- Вкладки: Daily / Weekly / All-time
- Таблица с мини-превью, автор, рейтинг, место
- Тематические лидерборды (напр. «Mirror Week»)

---

## Этап 5: Market + Profile + Paywall

### Market

- Два раздела: Objects / Spaces
- Карточки листинга: превью, редкость, цена, кнопки Buy Now / Make Bid
- Фильтры и поиск

### Profile

- Галерея публичных пространств пользователя
- Коллекции и значки/ачивки
- Витрина продаваемых предметов
- Статистика

### Paywall

- 3 карточки тарифов: Free / Pro / Pro+
- Сравнительная таблица фич
- Glassmorphism-карточки с gradient border для Pro+

---

## Технические детали

- **3D**: React Three Fiber (@react-three/fiber ^8.18) + Drei (^9.122.0) + Three.js
- **Данные**: mock-данные в JSON (без бэкенда), хранение состояния в React state/context
- **Анимации**: CSS transitions + Framer Motion для UI, Three.js для 3D
- **Адаптивность**: mobile-first, но работает и на десктопе
